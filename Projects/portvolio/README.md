# Professional Developer Portfolio

A modern, responsive portfolio built with Python and Django.

## Features
- **Modern UI**: Clean and minimal design using Vanilla CSS.
- **GSAP Animations**: Smooth reveal animations and scroll effects.
- **Dynamic Content**: Managed via Django's backend.
- **Contact Form**: Integrated contact section.

## Tech Stack
- **Backend**: Python, Django
- **Frontend**: HTML5, CSS3, JavaScript, GSAP, Tailwind CSS (via CDN)
- **Database**: SQLite

## Getting Started

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Run migrations**:
   ```bash
   python manage.py migrate
   ```
4. **Start the server**:
   ```bash
   python manage.py runserver
   ```
